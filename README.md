# Argha Basak — Portfolio

Personal portfolio of **Argha Basak**: Data Analyst · Business Analyst · AI & Automation Engineer.

**Live:** https://argha-basak.vercel.app

A single static page (`index.html`) with no build step: plain HTML, CSS and JavaScript.

- `index.html` — the whole site
- `assets/` — portrait, CV and skill icons
- `robots.txt`, `sitemap.xml` — search engine files

Pushing to `main` redeploys the site on Vercel automatically.
